📖 Xem hướng dẫn tạo bảng Supabase (3 bước đơn giản)

1. Đăng ký tài khoản miễn phí tại supabase.com và tạo 1 Project mới.

2. Vào menu SQL Editor, dán đoạn lệnh sau và bấm Run:

create table if not exists habit_data (
  id text primary key,
  data jsonb not null,
  updated_at timestamp with time zone default timezone('utc'::text, now()) not null
);
alter table habit_data enable row level security;
create policy "Allow public access" on habit_data for all using (true) with check (true);

3. Vào Project Settings ➔ API, sao chép Project URL và anon public key dán vào 2 ô trên.
